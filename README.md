# 银行AI智能助手·小智 2.0

基于大模型（GLM-4-Flash）的银行网点智能助手，覆盖五大场景：
智能查询、大额转账风控、反诈拦截、账单分析、适老关怀。

## 功能亮点
- 🧰 工具调用：AI 自动调用余额查询/转账工具，调用过程透明可解释
- 🛡️ 大额风控：单笔超 5000 元触发二次确认
- 🚨 反诈拦截：命中诈骗关键词即时告警 + 反诈劝阻话术
- 👵 适老关怀模式：大字号 + 白话话术
- 📊 客户数据看板
